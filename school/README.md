# Resume Portfolio Website

This is a static portfolio website you can link from your resume, email signature, LinkedIn, or job applications. It includes sections for projects, experience, schoolwork, skills, and contact links.

The project section now includes three small-company website demos:

- Peoria Heights Plumbing - https://verdant-nasturtium-1ba655.netlify.app/
- Bluetown Landscaping - https://tranquil-beignet-ce826c.netlify.app/
- Whiskey City Barbers - https://meek-cocada-9cc5ed.netlify.app/

## What's Included

- Joshua Lehman's name, email, phone, education, skills, and resume link.
- The Delta Upsilon 5K website project.
- SAE Formula frame work.
- Three small-company website demos.

## Run Locally

From this folder:

```powershell
node server.js
```

Then visit:

```text
http://localhost:5174
```

## Files

- `index.html` - page content and links
- `styles.css` - visual design and responsive layout
- `script.js` - project filter behavior
- `Resume Job Fair.pdf` - linked resume PDF
- `assets/portfolio-hero.png` - hero image
- `assets/sae-frame-cad.png` - SAE Formula frame CAD screenshot
